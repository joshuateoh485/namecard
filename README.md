# Yes Financial — Digital Namecard & Command Centre

Static site for **Teoh Sheak Yao** / **Yes Financial Bhd** & **Yes Trustees Bhd**.

## Pages

| File | What it is |
|------|------------|
| `index.html` | Animated digital business card |
| `office.html` | **Command Dashboard** + **AI Agent Office** (finance-floor view) |

Open `index.html` locally, or serve the folder:

```bash
python3 -m http.server 8765
```

Then visit `http://127.0.0.1:8765/` and `http://127.0.0.1:8765/office.html`.

Dashboard numbers are **illustrative demo data**, not live client performance.
