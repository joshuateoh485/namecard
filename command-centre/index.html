    Connect Grok Bots

    Grok Bot has no public list/chat API yet. Sync progress via a status URL your bots update, or paste a roster JSON.

    Official options today: Bot routine webhooks (start a run) and MCP tools your bots can call. This dashboard reads a JSON status feed.

    Tip: in each Grok Bot chat, ask it to POST progress to your status endpoint (or update a shared gist/file) with fields id/name/status/progress/task. Map grokName to the Bot’s sidebar name.
